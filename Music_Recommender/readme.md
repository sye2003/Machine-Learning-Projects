# Music ML Project

Welcome to the Music ML project! This repository contains resources and code for building, training, and visualizing machine learning models for music recommendation and classification using scikit-learn.

## Project Overview

This workspace demonstrates:
- Data analysis and preprocessing with pandas
- Model training and evaluation using scikit-learn
- Saving and loading models with joblib
- Visualizing decision trees with Graphviz and SVG

## Contents

- **helloworld.ipynb**: Jupyter notebook with code examples and experiments.
- **music.csv**: Dataset for music recommendation/classification.
- **vgsales.csv**: Additional dataset for machine learning practice.
- **music-recommender.joblib**: Pre-trained music recommender model.
- **music-recommender.dot**: Decision tree structure in DOT format.
- **decision-tree_algorithm.svg**: Visual representation of the decision tree.

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/music-ml.git
   cd music-ml
   ```
2. Install dependencies:
   ```bash
   pip install scikit-learn pandas joblib notebook
   ```
3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Open `helloworld.ipynb` to explore code and run experiments.

## Usage

- Use the provided datasets for training and testing models.
- Load `music-recommender.joblib` to make predictions without retraining.
- Visualize decision trees using the `.dot` and `.svg` files.

## Requirements

- Python 3.x
- scikit-learn
- pandas
- joblib
- Jupyter Notebook

## Visualization

- View the decision tree structure with Graphviz (`music-recommender.dot`).
- Open `decision-tree_algorithm.svg` for a graphical representation.
