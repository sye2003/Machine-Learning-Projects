## Electricity Cost Predictor

This project predicts electricity costs for different building types using machine learning. It includes a Streamlit web app for interactive predictions and a Jupyter notebook for model training and visualization.

**Project Structure**


electricity_app.py: Streamlit web application for electricity cost prediction.
main.ipynb: Jupyter notebook for data analysis, model training, and visualization.
electricity_cost_dataset.csv: Dataset containing features and electricity cost values.
.gitignore: Git ignore file for common Python and Jupyter artifacts.
How to Run
1. Install Requirements
2. Start the Streamlit App
3. Use the Jupyter Notebook
Open main.ipynb in JupyterLab or VS Code to explore model training and evaluation.

**Dataset Columns**

1. site area
2. structure type
3. water consumption
4. recycling rate
5. utilisation rate
6. air qality index
7. Issue resolution time
8. resident count
9. Electricity cost
    
**Features**
1. Interactive web app for cost prediction
2. Linear regression model
3. Data visualization in Jupyter Notebook
